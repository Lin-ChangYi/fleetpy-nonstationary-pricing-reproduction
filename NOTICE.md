This release contains research-specific code adapted to run with FleetPy.

FleetPy is available under the MIT License:
https://github.com/TUM-VT/FleetPy

The public Manhattan simulation inputs are distributed separately through the
FleetPy Manhattan Zenodo record:
https://doi.org/10.5281/zenodo.15187906

The underlying historical demand source is the NYC Taxi and Limousine
Commission public trip-record data:
https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page
